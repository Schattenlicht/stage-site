Dein Freischaltcode ist unterwegs.

Dein Code kommt per Mail

Gleich nach deiner Zahlung schickt dir der Server eine Mail mit deinem persönlichen Freischaltcode. Sie geht an die Mail-Adresse, die du bei Ko-fi angegeben hast. Das dauert normalerweise nur wenige Minuten.

Wenn nach einer Viertelstunde nichts da ist, schau bitte im Spam-Ordner nach. Findest du sie dort nicht, antworte auf die Kaufbestätigung von Ko-fi oder schreib mir über das Impressum. Ich schicke dir deinen Code dann von Hand.

So löst du den Code ein

  1. Öffne Schattenlicht Stage auf deinem PC. Du hast es noch nicht? Hier geht es zum Download.
  2. Gehe auf Einstellungen und öffne den Bereich Freischaltcodes.
  3. Trage deinen Code ein und klicke auf Einlösen. Dafür braucht Stage einmal eine Internetverbindung, und die Online-Funktionen müssen eingeschaltet sein.
  4. Der Stil steht danach unter Stil wechseln bereit.

Gut zu wissen

  • Dein Code gilt für bis zu zwei Geräte. Wechselst du den PC, kannst du die Lizenz in Stage auf dem alten Gerät freigeben (zweimal pro Jahr) und den Code auf dem neuen Gerät wieder eingeben.
  • Du darfst den Stil in deinen eigenen Streams nutzen, auch mit Einnahmen. Den Code und die Dateien weiterzugeben oder zu verkaufen ist nicht erlaubt.
  • Stage selbst bleibt kostenlos. Dein Kauf unterstützt die Weiterentwicklung.
